## Profiles

| Profile | Use | Database / API |
|---|---|---|
| `local-mock` (default) | Minimal server demo | DataSource auto configuration excluded; no Gemini client; no persistent or mock repository yet |
| `test` | Spring/JUnit smoke tests | DataSource auto configuration excluded; no Gemini client |
| `oracle` | Future Oracle 26ai persistence | Requires `ORACLE_JDBC_URL`, `ORACLE_DB_USER`, `ORACLE_DB_PASSWORD`; no mock fallback |
| `oracle-it` | Explicit integration suite via `-Poracle-it verify` | Reserved for future `*OracleIT.java` tests, used with `oracle`; never part of normal `test` |

Oracle AI Database 26ai Free server is **not installed**. STEP 01 does not install Oracle, create accounts/schema, or execute SQL. The existing `src/main/resources/db/sampledb.sql` is an unused template artifact, not the target schema and never executed. Oracle JDBC dependency and actual connectivity are not established in STEP 01. `/health` reports only the HTTP process; it does not certify database readiness.

`.env.example` is illustrative and is not loaded automatically. Use process environment variables only when an explicit future Oracle run is authorized. No Gemini key or call is required for this step.
